DigitalInvoice is Teecoms Integrated Solutions Limited's electronic invoicing application for Nigerian businesses. This documentation centre brings together the technical reference material, invoice structures and supporting documents needed by integrators and reviewers. The documentation tracks the current NRS MBS technical guidance (v1.1), and its published data mapping is revised as official requirements evolve. The [implementation timeline](/developers/timeline/) outlines the delivery milestones and external dependencies.

Explore the API and data contracts, inspect eight downloadable fictional PDF examples, and review the system architecture and security overview. The documents reflect the DigitalInvoice implementation, including **Phase 5 sandbox resource synchronisation and invoice-validation safeguards**, and distinguish existing local code from external test evidence, approved service commitments effective 27 November 2026 and licence-gated integrations.

:::info Reading these documents
Technical examples and sample PDFs are illustrative. An implemented schema or integration flow does not establish NRS licensing, production connectivity or official invoice validation. The [Service Level Agreement](/sla/) is approved, with effect from **27 November 2026**. Teecoms Integrated Solutions Limited **is certified to ISO/IEC 27001:2022**; see the [security and certification overview](/developers/security/) for certificate details and verification links.
:::
