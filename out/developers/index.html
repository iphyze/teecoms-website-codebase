Developer resources

DigitalInvoice developers

Public DigitalInvoice API, invoice schema, document samples, architecture, security and service-level documentation from Teecoms.

Version 1.1Updated 2026-11-25published

On this page

  1. Documentation library

DigitalInvoice is Teecoms Integrated Solutions Limited's electronic invoicing application for Nigerian businesses. This documentation centre brings together the technical reference material, invoice structures and supporting documents needed by integrators and reviewers. The documentation tracks the current NRS MBS technical guidance (v1.1), and its published data mapping is revised as official requirements evolve. The implementation timeline outlines the delivery milestones and external dependencies.

Explore the API and data contracts, inspect eight downloadable fictional PDF examples, and review the system architecture and security overview. The documents reflect the DigitalInvoice implementation, including Phase 5 sandbox resource synchronisation and invoice-validation safeguards, and distinguish existing local code from external test evidence, approved service commitments effective 27 November 2026 and licence-gated integrations.

Reading these documents

Technical examples and sample PDFs are illustrative. An implemented schema or integration flow does not establish NRS licensing, production connectivity or official invoice validation. The Service Level Agreement is approved, with effect from 27 November 2026. Teecoms Integrated Solutions Limited is certified to ISO/IEC 27001:2022; see the security and certification overview for certificate details and verification links.

Integration status

A concise summary of which capabilities are implemented and which remain subject to external access or approval.

Application and ERP integration

Invoice workflows, a read-only ERP API using OAuth 2.0 client credentials, and signed outbound webhooks are implemented. Availability is subject to organisation permissions and configuration.

Implemented

NRS MBS preparation

The UBL-style adapter, local readiness checks and credential-gated sandbox client exist. Sandbox capability does not mean a live NRS integration has been established.

Sandbox-controlled

ISO/IEC 27001:2022 certification

Teecoms Integrated Solutions Limited is certified to ISO/IEC 27001:2022 for its Information Security Management System (certificate SCK/05/TIS/26/23/9804). Certificate details and verification are in the security overview; independent DigitalInvoice VAPT remains in progress.

Certified

NRS production submissions

Live NRS submission and official clearance/verification are disabled pending MBS licensing and production activation. Fictional demonstration evidence is not official NRS evidence.

Licence-gated

For implementation detail, see the architecture and security documentation.
